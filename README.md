# Бумажный компас

Сайт серии тетрадей-приключений по математике (автор А. Эларин).

Открыть: https://tikhora-games.github.io/paper-compass-site/

- **Истории** — живые страницы книг с героями.
- **Тренажёры** — таблица умножения, деление с остатком, столбик, уголок, логика.
- **Листы** — генератор листов для печати и шифровок.
- **Задача дня** и **журнал** со значками (прогресс хранится только в браузере).

Книги — на Литрес: https://www.litres.ru/author/a-elarin-34117204/
